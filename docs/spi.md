SPI 全称是 **Serial Peripheral Interface，串行外设接口**，常用于 MCU 与传感器、存储器、显示屏之间通信。

常规 SPI 使用以下四类信号：

| 信号 | 名称 | 作用 |
| --- | --- | --- |
| SCK | 串行时钟 | 主机产生时钟，协调每一位数据的传输 |
| MOSI | 主机输出、从机输入 | 主机向从机发送数据 |
| MISO | 主机输入、从机输出 | 从机向主机发送数据 |
| CS / NSS | 片选 | 选择此次通信的从机，通常低电平有效 |

**SPI传送字节的方式 （全双工）：**

1. 主机拉低目标设备的 CS。
2. 主机产生 8 个时钟周期。
3. 每个周期通过 MOSI 发出一位，同时通过 MISO 接收一位。
4. 传输完成后释放 CS。

**SPI 的主要特点：**

- **同步通信**：有独立时钟线，由主机提供时钟。
- **通常支持全双工**：MOSI、MISO 分别负责两个方向。
- **速度通常较高、协议开销较小**：适合较频繁的数据读取。
- **通过片选选择设备**：没有像 I²C 那样统一的设备地址机制。
- **引脚需求较多**：设备增加时，片选线也通常增加。
- **需要匹配时钟模式**：双方的 CPOL、CPHA 必须一致。
- **基本 SPI 没有统一的 ACK 或校验机制**：需要依靠具体设备协议检查通信结果。

在工程中，STM32 是 SPI1 主机，BMI088 的加速度计与陀螺仪共享 SCK、MOSI、MISO，分别通过 **PA4、PB0 两路 CS** 选择。当前配置为 Mode 3、2.625 MHz。
